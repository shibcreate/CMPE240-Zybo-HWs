xpar_remap.h  (from phase1 + phaselast, heavily rewritten)
----------------------------------------------------------------------
  phase1 had:  basic SDT remaps for audio (I2S, I2C, DMA, GIC)
  phaselast had: SDT remaps for HDMI (VDMA, VTC, dynclk, UART)

  Project version combines both and adds:
  - New student header comment
  - #include "xscugic.h" for XSCUGIC_SPI_INT_ID_START
  - Audio remaps: I2S baseaddr, I2C, DMA, GIC device IDs
  - HDMI remaps: VDMA device ID, VTC out device ID, dynclk baseaddr
  - Critical interrupt mappings with +32 (XSCUGIC_SPI_INT_ID_START):
      XPAR_FABRIC_AXI_IIC_0_IIC2INTC_IRPT_INTR
      XPAR_FABRIC_AXI_DMA_0_S2MM_INTROUT_INTR
      XPAR_FABRIC_AXI_DMA_0_MM2S_INTROUT_INTR
      XPAR_FABRIC_AXI_GPIO_0_IP2INTC_IRPT_INTR
  - 16 lines added vs phase1, completely rewritten vs phaselast

----------------------------------------------------------------------

  display_ctrl/xvtc_hw.h    - VTC hardware defs (using BSP version)

  timer_ps/timer_ps.h       - PS timer header
  video_capture/video_capture.c  - HDMI input capture (not needed)
  video_capture/video_capture.h  - HDMI input capture header
  video_capture/xvtc.h      - duplicate VTC header
  video_capture/xvtc_hw.h   - duplicate VTC hardware defs
  video_demo.c              - Digilent's HDMI demo main (replaced by demo.c)
